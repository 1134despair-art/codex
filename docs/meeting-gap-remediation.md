# 物联二路 1 号会议调整项整改清单

## 1. 文档目的

本文用于跟踪《物联二路1号_Word未提及调整项.md》中与后台管理系统相关、且当前 Demo 明确缺失或仅部分实现的内容。读者为产品、前端、后端和测试人员。

本轮不纳入会议中标记为“待确认/讨论建议”的 `U01-U09`，不把静态 Demo 描述为真实设备、支付、推送或并发服务。需要后端或第三方服务的能力，在 Demo 中只实现确定性数据流和可追踪记录。

## 2. 状态定义

| 状态 | 判定标准 |
| --- | --- |
| 待整改 | 没有页面、字段或数据实体 |
| 部分实现 | 已有入口，但字段、权限、状态流或关联数据不完整 |
| Demo 完成 | 页面、数据变化、权限、日志和自动化测试均可验证 |
| 后端边界 | Demo 可记录配置或结果，真实调用需要后端交付 |

## 5. 权限与数据规则

- 超级管理员负责平台管理员和全局版本配置；普通平台管理员不能修改超级管理员身份。
- 产品、版本、OTA、跨区审核和平台账单由平台角色维护。
- 一级经销商只能管理自身及下级数据；二级经销商只能管理自身数据。
- 经销商只能配置自身质保规则，平台可查看全部规则和历史。
- 导出、审批、转派、库存扣减、价格修改和版本发布均写操作日志。
- 无权限返回权限错误；有权限但无数据返回空状态，两者不得混用。

| `billing-items` | 账单 ID、费用类型、数量/工时、单价、小计、调整金额 |

## 7. 测试与验收

- 单元测试覆盖唯一超级管理员、身份编号唯一性、价格历史、质保历史、采购汇总、账单汇总、库存预占和释放。
- Playwright 覆盖新增菜单、筛选、工单转总部、FAQ 型号配置、版本发布和更换登记。
- 回归平台、一级经销商、二级经销商菜单及数据范围。
- 执行 `vue-tsc`、ESLint、Vitest、生产构建和完整 Playwright。
- 保持纯前端 Demo 可重复演示，刷新后数据保留，一键恢复示例数据后回到种子状态。

## 8. 后端交付边界

- 设备连接回读、固件推送、回滚执行、支付、物流和消息推送仅记录模拟结果。
- APP 与后台共享账号、配置、绑定、工单和版本数据需要统一服务端数据库与 API。
- 并发超卖、分布式事务、文件存储、病毒扫描和大数据量异步导出需由后端实现。
