# 后台 V3.2 全菜单自动化验收记录

验收日期：2026-08-12

验收基线：后台管理系统 V3.2。后台未定义新增入口的业务，不为演示额外扩展“新增”功能；来自 App、设备或第三方平台的数据使用稳定种子数据进入后台流程。

| 设备管理 | 新增、地区修改、远程启停、解绑 | 自动生成固件/激活/绑定状态，写入归属和命令日志 | 远控为确定性静态模拟 | 通过 |

| 换 SN 管理 | 经销商发起并确认 | 原 SN 归档、新设备、项目、航点、归属历史同步 | 原 SN 归属和新 SN 唯一性校验 | 通过 |
| 售后转移 | 原经销商发起、目标经销商确认 | 设备经销商关系和归属历史同步 | 仅合法上级或同级目标 | 通过 |

| 操作日志 | 查询、筛选、详情、导出 | 各业务动作自动生成日志 | 日志只读，不允许修改或删除 | 通过 |

## 自动化证据

- `tests/unit/menu-flows.spec.ts`：24 菜单 service 行为、维护数据 CRUD、只读限制、跨角色审批和外部模拟边界。
- `tests/e2e/admin.spec.ts`：24 菜单、全部 Tab、可用详情、真实表单新增、跨角色审批、工单状态流和多视口检查。
- `tests/unit/database.spec.ts`：本地事务回滚、版本迁移、账号迁移和持久化。
- `tests/unit/mock.spec.ts`：权限、数据范围、状态机、库存、SN 和关联数据联动。

最终结果：24/24 菜单可访问，16/16 浏览器流程通过，外部服务只做明确标识的静态模拟。
